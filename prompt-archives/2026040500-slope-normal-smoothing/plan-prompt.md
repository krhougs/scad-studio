## 背景

- 用户先反馈“渲染出来的一些斜面会出现大量的三角形”。
- 代码排查确认：当前预览链路为 `OpenSCAD -> 3MF -> MeshTriangle -> MeshData -> shader`。
- 当前 `MeshData::from_triangles` 会把每个三角面的 3 个顶点直接写入 GPU，并把同一个面法线复制给这 3 个顶点；不存在共享顶点后的平滑法线计算。
- 目标不是修改 OpenSCAD 导出格式，也不是整体重写渲染器，而是在现有网格构建阶段修复法线策略，降低斜面上的三角片明暗分块。

## 本轮用户请求

1. 为什么渲染出来的一些斜面会出现大量的三角形
2. 尝试修复上面的三角形问题

## 注意事项

- 以当前根目录可执行程序 `src/main.rs` 这套代码为准，不以 `crates/scad-ui` 的迁移中代码为准。
- 只允许修改与网格法线生成直接相关的代码，避免顺手改动渲染管线、UI、OpenSCAD 调用参数。
- 需要先写失败测试，再写实现。
- 需要保护现有目标：
  - STL / 3MF 导入仍然能够生成可渲染的 `MeshData`
  - 颜色字段透传逻辑不变
  - 锐边不能因为平滑法线而整体变圆
