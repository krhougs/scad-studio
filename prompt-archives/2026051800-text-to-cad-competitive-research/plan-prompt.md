# 竞品调研：earthtojake/text-to-cad 与 AI CAD 生态分析

## 任务背景

用户要求针对 https://github.com/earthtojake/text-to-cad 项目及其周边宣传进行深度调研（排除 URDF/SRDF/机械手臂部分），围绕 budn' 的产品定位（消费电子、工业零件、业余 3D 打印）输出竞品分析报告。

## 调研维度

0. 明确 budn' 产品定位：高质量消费电子/工业零件/业余 3D 打印的 CAD 建模
1. CadQuery / build123d 及其他编程式 CAD 方案的优缺点对比（必须开源且支持 STEP 工作流）
2. 面向域外用户和初学者的推广策略
3. 参照 text-to-cad 的 Explorer，设计 budn' 的 Web App 体验
4. 从 text-to-cad 的技能体系中提取 budn' Agent 的能力缺口
5. 创建更多场景和目标，用于基准测试

## 输出要求

- 中英双语研究报告，确保中国大陆和美国读者均可无障碍阅读
- 包含具体可执行建议
