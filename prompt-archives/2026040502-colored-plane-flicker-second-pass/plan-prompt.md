## 背景

- 上一轮已把彩色模式的高光从 `1.0` 降到 `0.3`，并将高光颜色向底色收敛。
- 用户反馈白色闪烁仍然存在。
- 进一步排查：
  - 当前默认运行态仍为 `Solid + Color + 阴影关闭`
  - 本机 OpenSCAD 导出的最小彩色斜面 3MF 是单对象单层彩色网格，不是天然重叠 build item
- 因此第二轮更高概率的残留根因，是彩色模式下仍然保留了非零白色视角高光项。

## 本轮目标

- 在彩色模式下彻底去掉 `Solid` 模式的白色高光。
- 同时将 `X-Ray` 的白色 fresnel 收敛到彩色底色，避免另一条渲染路径残留白色闪烁。

## 注意事项

- 继续保护网格、3MF 解析和前一轮法线修复。
- 只改 `pipeline / shader / tests`。
