## Phase 1: 建立透明面拆分测试

### 输入

- 当前 `MeshData` 只保存单一 `indices`，不区分透明与不透明三角面。

### 要保护的前序目标 / 边界

- 不改动前两轮的法线平滑逻辑和已有测试预期。
- 不修改 3MF 解析结构。

### 操作步骤

1. 在 `tests/mesh_tests.rs` 新增最小测试。
2. 使用混合 alpha 的三角面构造 `MeshData`。
3. 约束内部应能导出透明与不透明索引分区。
4. 先运行测试，确认在现状下失败。

### 验收标准

- 新测试先失败，失败原因指向当前缺少 alpha 分区能力。

## Phase 2: 实现 Solid 模式透明/不透明分离绘制

### 输入

- Phase 1 的失败测试。

### 要保护的前序目标 / 边界

- 保持不透明三角面的现有绘制路径。
- 不动 `X-Ray` 的整体绘制结构，只做必要兼容。

### 操作步骤

1. 在 `src/mesh.rs` 为 `MeshData` 增加按三角面 alpha 拆分索引的纯函数能力。
2. 在 `src/renderer.rs` 中为 mesh 保留透明与不透明索引缓冲。
3. 在 `src/pipeline.rs` 中补透明 Solid 管线，使用 alpha blend 且关闭深度写入。
4. 在 `src/shader.wgsl` 中让彩色模式输出真实 model alpha，供透明 pass 使用。

### 验收标准

- Phase 1 测试转绿。
- 透明三角面不再与不透明背板共用同一深度写入路径。
