## 背景

- 用户最新症状：
  - 屏幕区域闪烁
  - 摄像机离得近基本不闪
  - 拉远后稳定复现
- 这与典型深度精度问题高度一致。
- 当前相机投影仍然固定使用：
  - Perspective near/far = `0.01 .. 10000.0`
  - Orthographic near/far = `0.01 .. 10000.0`
- 对 `mini_itx_pc_003.scad` 这种毫米级细节 + 远距离观察场景，这个深度范围过大，会显著降低屏幕区域相近表面的深度分辨率。

## 本轮目标

- 基于场景包围盒收紧相机近远裁剪面。
- 让渲染和截面交互使用一致的收紧后投影矩阵。
