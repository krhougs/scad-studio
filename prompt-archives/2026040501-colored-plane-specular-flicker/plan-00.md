## Phase 1: 建立高光策略回归测试

### 输入

- 现状：彩色模式与单色模式在 shader 中都使用白色高光。
- 目标文件：
  - `tests/pipeline_tests.rs`
  - `src/pipeline.rs`

### 要保护的前序目标 / 边界

- 不改动上一轮网格法线逻辑。
- 不改变已有颜色模式、线框模式和雾化开关的现有语义。

### 操作步骤

1. 为着色管线新增“高光强度策略”测试。
2. 约束彩色模式的高光强度低于单色模式。
3. 先运行相关测试，确认在现状下失败。

### 验收标准

- 新测试先失败。
- 失败原因直接指向当前缺少针对 `ColorMode` 的高光差异化策略。

## Phase 2: 下发并应用彩色模式高光配置

### 输入

- Phase 1 的失败测试。

### 要保护的前序目标 / 边界

- 保持 `ColorMode::Mono` 的现有单色外观基调。
- 不为了压掉白块而整体移除所有高光。

### 操作步骤

1. 在 `src/pipeline.rs` 增加高光强度配置函数。
2. 在 `src/renderer.rs` 将该配置写入现有 uniform。
3. 在 `src/shader.wgsl` 与 `src/shader_xray.wgsl` 中：
   - 读取新的高光强度
   - 在彩色模式下将高光颜色向底色收敛，避免纯白高光块
4. 保持改动最小，不额外重构 shader 结构。

### 验收标准

- Phase 1 测试转绿。
- 彩色模式与单色模式的高光策略已分离。

## Phase 3: 回归验证

### 输入

- 已完成实现的变更。

### 要保护的前序目标 / 边界

- 不破坏网格、3MF、颜色模式基础能力。

### 操作步骤

2. 运行 `pipeline`、`mesh`、`three_mf` 相关测试。
3. 记录结果和遗留风险。

### 验收标准
