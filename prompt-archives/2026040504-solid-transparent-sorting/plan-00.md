## Phase 1: 建立透明三角面排序测试

### 输入

- 当前 `MeshData` 只能分离透明索引，还不能按相机位置排序透明三角面。

### 要保护的前序目标 / 边界

- 不回退透明/不透明分离能力。
- 不引入 GPU 依赖测试。

### 操作步骤

1. 在 `tests/mesh_tests.rs` 新增纯函数测试。
2. 构造两个透明三角面和一个固定相机位置。
3. 要求输出索引顺序为 back-to-front。
4. 先运行测试，确认在现状下失败。

### 验收标准

- 新测试先失败。

## Phase 2: 实现透明三角面排序

### 输入

- Phase 1 的失败测试。

### 要保护的前序目标 / 边界

- 保持不透明三角面绘制顺序和索引结构不变。
- 只为透明三角面增加排序，不重写整个渲染架构。

### 操作步骤

1. 在 `src/mesh.rs` 增加基于相机位置的透明三角面排序函数。
2. 在 `src/renderer.rs` 的 Solid 透明 pass 中，每帧按当前相机眼睛位置更新透明索引缓冲顺序。
3. 仅修改透明 pass，不影响 `X-Ray` 和不透明 pass。

### 验收标准

- Phase 1 测试转绿。
- 透明 pass 使用排序后的索引缓冲。
